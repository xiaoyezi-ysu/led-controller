# LED远程灯控系统 — 标准操作流程 (SOP)

## 1. 硬件指示灯说明

### 4G模组指示灯（飞思创DTU）

| 指示灯 | 状态 | 含义 |
|--------|------|------|
| **电源指示灯（红灯）** | 常亮 | 电源正常 |
| | 熄灭 | 未通电/电源异常 |
| **网络指示灯（蓝灯）** | 慢闪（200ms亮/1800ms灭） | 搜索网络/注册网络中 |
| | 慢闪（1800ms亮/200ms灭） | 已注册网络，未连接服务器 |
| | 快闪（125ms亮/125ms灭） | 已连接服务器，数据通信正常 |
| | 熄灭 | 未启动 |

### 车牌板LED（红/黄/绿）

| LED | 状态 | 含义 |
|-----|------|------|
| 红（PB12） | 亮/灭 | 应用控制 |
| 黄（PB13） | 亮/灭 | 应用控制 |
| 绿（PB14） | 亮/灭 | 应用控制 |

### 最小板LED

| LED | 状态 | 含义 |
|-----|------|------|
| PC13 | 亮/灭（低电平有效） | 应用控制 |

## 2. 上电启动流程

```
[上电] → [4G红灯常亮] → [蓝灯慢闪-200/1800ms 搜索网络] 
       → [蓝灯慢闪-1800/200ms 已注册] 
       → [蓝灯快闪-125/125ms MQTT已连接] 
       → [模块就绪，等待20s后发ready] 
       → [可远程控制]
```

**步骤说明：**
1. 给模块通电，红色电源指示灯常亮
2. 蓝色网络指示灯开始慢闪（200ms亮/1800ms灭），表示正在搜索/注册网络
3. 注册成功后蓝灯变为1800ms亮/200ms灭，表示已注册但未连接MQTT服务器
4. 模块自动连接MQTT服务器，成功后蓝灯快闪（125ms亮/125ms灭）
5. 连接建立后约20秒，模块通过MQTT发布 `{"cmd":"ready","id":"<ICCID>"}` 到 `DTU_Topic1147/<ICCID>`
6. 此时Web App上对应设备状态变为在线，可远程控制

> ⚠️ **等待时间：** 从通电到可远程控制约需 20~30秒，请耐心等待ready信号

## 3. Web App操作说明

### 访问地址
- GitHub Pages：`https://xiaoyezi-ysu.github.io/led-controller/led_app.html`
- 本地测试：`http://localhost:8080/led_app.html`（需运行 `serve.py`）

### 界面功能

#### 连接MQTT
1. 输入设备号（ICCID），或从设备列表选择已有设备
2. 点击 **连接** 按钮
3. 连接成功后状态栏显示 **已连接**，日志区显示 `已连接 MQTT`

#### 设备管理
- **选择设备：** 点击设备列表中某设备，自动填入设备号
- **添加设备：** 输入名称和ICCID，点击 **添加**
- **编辑设备：** 点击设备旁的 **编辑** 按钮修改名称或ICCID
- **删除设备：** 点击 **删除** 移除设备（设备列表存储在浏览器localStorage）

#### 灯控操作
确认已连接且选择了正确设备后：

| 按钮 | 发送命令 | 效果 |
|------|----------|------|
| 🔴 红灯 | `{"cmd":"led","color":"red","state":"on"}` | 该设备红灯亮 |
| 🟡 黄灯 | `{"cmd":"led","color":"yellow","state":"on"}` | 该设备黄灯亮 |
| 🟢 绿灯 | `{"cmd":"led","color":"green","state":"on"}` | 该设备绿灯亮 |
| ⭕ 关闭 | `{"cmd":"led","color":"all","state":"off"}` | 该设备全部LED关 |

- **亮度滑块：** 调节LED亮度（0~255），松开发送

#### 注意事项
- 设备号ICCID需与模块实际ICCID一致（写在模块标签上）
- 发送命令后日志区显示绿色 `sent` 消息，模块收到后返回 `{"ack":"ok"}`（蓝色 `recv` 消息）
- 设备默认每20秒发送心跳包保持连接

## 4. MQTT主题架构

| 方向 | 主题 | 用途 |
|------|------|------|
| Web App → 设备 | `xiaoyeziUESTC1147/<ICCID>` | 发送灯控命令 |
| 设备 → Web App | `DTU_Topic1147/<ICCID>` | 设备上报状态/ACK |
| Web App 订阅 | `DTU_Topic1147/+` | 通配符接收所有设备消息 |

> 每个模块只订阅自己的 `xiaoyeziUESTC1147/<ICCID>` 主题，Web App订阅 `DTU_Topic1147/+` 通收全部。

## 5. 故障排查

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 红灯不亮 | 未通电 / 电源异常 | 检查12V电源和接线 |
| 蓝灯一直慢闪(200/1800ms) | SIM卡问题/信号差 | 检查SIM卡安装、天线连接 |
| 蓝灯一直慢闪(1800/200ms) | MQTT服务器无法连接 | 检查MQTT服务器配置 |
| Web App连接不上MQTT | 网络问题/WSS端口被封 | 检查浏览器是否可访问 `wss://broker.emqx.io:8084` |
| 发送命令无响应 | 设备未就绪/ICCID不对 | 检查设备列表ICCID是否正确 |
| 设备不在线 | 模块未发ready/已掉线 | 等待20秒或断电重启模块 |

## 6. 烧录固件

使用MKLink烧录：
```bash
mklink --connect COM9 --flash-minichlink firmware/xxx.hex
```

必须先 `erase_chip` 再 `flash`，否则报 status:17。
