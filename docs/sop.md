# LED远程灯控系统 — 操作说明

## 1. 接线

- **电源：** 模块接 12V 电源（VBAT）
- **指示灯：** 通电后红灯常亮
- （模块出厂已配置好，无需额外接线）

## 2. 等待模块启动

通电后观察蓝色网络灯：

| 蓝灯状态 | 含义 |
|-----------|------|
| 慢闪（一亮一灭间隔较长） | 正在搜索网络，请等待 |
| **快闪（快速闪烁）** | ✅ **网络已连接，可以对模块进行控制了！** |

⏱ 从通电到快闪约需 **20~30 秒**，请耐心等待。

## 3. 手机/电脑远程控制

用手机或电脑浏览器打开：

**https://xiaoyezi-ysu.github.io/led-controller/led_app.html**

操作步骤：
1. 点 **连接** 按钮（自动连接MQTT服务器）
2. 从设备列表选择要控制的设备（已保存的设备可直接点选）
3. 点 **红灯 / 黄灯 / 绿灯 / 关闭** 按钮即可控制灯光
4. 拖动 **亮度滑块** 可调节灯光亮度

---

> **提示：** 每个模块对应一个唯一的 ICCID 设备号，出厂已绑定。如模块无响应，请检查蓝灯是否为快闪状态。
