## 电源树（ver2）

```
Solar2 光伏板 ──D3(SS34)──┬── U8 CN3142（如韵太阳能充电 IC，Iq 3µA；无光照自动睡眠 <3µA）
                          │        └── BAT+（单节锂电，端子 BAT+）
                          └── VBAT ──┬── U4 ME6206A33 LDO（Iq 8µA）── VCC33 ── MCU/传感器/LED/上拉
                                     ├── R60 100k → PMOS-Q2(AO3401A) 栅（源接 VBAT）→ 漏 = V4G → 4G 模组 pin7
                                     │     └── PA3 ──R59 1k── Q5(AO3400A) 栅，R57 100k 下拉
                                     ├── R61 100k → PMOS-Q1(AO3401A) 栅 ── 漏 → R7 100k → ADC_BAT 分压
                                     │     └── PA2(BAT_EN) ──R29 1k── NMOS-Q5(AO3400A) 栅，R30 100k 下拉
                                     └── U6 DW03 锂电保护
```

**关键结论（与旧图不同）**
1. **4G 模组挂在 VBAT 侧**（VBAT → PMOS-Q2 → V4G → 模组 pin7），**不在 VCC33 上**。
2. **ver2 有 NRST 网络**：`U3 pin7 + C11 100nF + R21 10k 上拉 + SW4 复位按键`；**板上有 BOOT0 按键 SW2**（SW2 pin1=BOOT0，pin2=VCC33）。
3. 调试口 = `DOWNLOAD`（1x4P：pin1 VCC33 / pin2 SWDIO / pin3 SWCLK / pin4 GND），**仍无 NRST 引脚**（但可手按 SW4）。
4. 串口口 = `CHUAN`（1x4P：pin1 GND / pin2 VCC33 / pin3 RX3 / pin4 TX3）= USART3 → PC。
5. LED 驱动方式：**MCU 引脚 → 220Ω → NMOS 栅**（栅有 100k 下拉），5050 RGB 阳极经 **150Ω（红/黄）／100Ω（绿）** 接 VCC33，共阴到 NMOS 漏。
6. **LEDB2（蓝）+ R24 510Ω 是"跨 VCC33 常亮"的**（GND–LED–510Ω–VCC33），固件关不掉 → 常耗 ~1.0~1.3 mA。

## VCC33 上的负载清单（探针喂 VCC33 时全部计入）

| 元件 | 说明 | 常态电流 |
|---|---|---|
| U3 STM32F103C8T6 | pin9/24/36/48 = VDD | Sleep@8MHz 数 mA（见下） |
| U1 SC7A20HTR 加速度计 | pin3/7/11 | ~2 µA（低功耗模式） |
| R24 510Ω → LEDB2 蓝 | **常亮，关不掉** | **~1.0~1.3 mA** |
| R23 510Ω → LEDG2 翠绿 | PB8 驱动，固件把 PB8 配成模拟输入 → 灭 | ~0 |
| R15/R27/R28 150Ω → LEDR1 阳极 | Q2(AO3400A) 栅 = PA6 via R10 220Ω，R13 100k 下拉 | 灭时 0 |
| R16/R25/R26 150Ω → LEDY1 阳极 | Q3 栅 = PA7 via R11 220Ω，R1 100k 下拉 | 灭时 0 |
| R17/R20/R22 100Ω → LEDG1 阳极 | Q4 栅 = PB0 via R12 220Ω，R14 100k 下拉 | 灭时 0 |
| R5/R6 4.7k | I2C(SDA/SCL) 上拉到 VCC33 | 空闲高 → 0 |
| R18 10k | SWDIO 上拉到 VCC33 | 探针拉低时 ~0.33 mA |
| R21 10k | NRST 上拉 | 0（NRST 高） |
| R19 10k | SWCLK 下拉到 GND | 0 |
| C5~C24 等 15 只 | 去耦电容 | 0 |
| CHUAN pin2 / DOWNLOAD pin1 / SW2 pin2 | 排针/按键 | 0 |

**VCC33 上"能持续吃电"的只有：MCU + LEDB2（~1.2 mA）+ 零星上拉。**
