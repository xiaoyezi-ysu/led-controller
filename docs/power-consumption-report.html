读数说明

  • 耗电大头是 4G 模组：所有档位电流下限落在 33–36 mA，是模组维持 MQTT 的基础电流，周期性注册/心跳突发可冲到 100–156 mA。
  • 睡眠态有效但不够"深"：MCU 进 WFI + 停心跳/探活，模组仍全供电、keepalive 照跑，且模组心跳/回显会把 MCU 唤醒，所以是"MCU 休息、模组值班"。
  • LED 贡献无法分离：4G 突发噪声远大于 LED 差异（绿灯 255 反而录到 97.79 mA，明显撞上突发）。要单独测 LED 需先 v4g off 断模组。
  • 样本偏少：每档仅 6 点（间隔 0.5 s），avg 抖动可达 20–30 mA，下结论建议 n≥30。
  • 测的是整板总线电流：MCU + 4G + LED + 传感器混在一起，分不出单项。电压稳定在 3364–3374 mV。

未测：4G 模组断电档

  • 补测流程：先关灯 → 采基线 → v4g off → 采 6 次 → 立刻 SWD 恢复 PA3 → 等待重入网并核对 ready 心跳。
