# LED车牌灯控系统 — 操作说明

**控制设备ID（车牌板）：** `89860812192380777521`

---

## 1. 接线

模块接 12V 电源（VBAT），通电后红灯常亮。

> ⚠️ **展示时才接电，用完后立即断电。** 模块持续搜网 + 连接服务器会耗光蓄电池，满电约可连续工作半小时。

---

## 2. 等待模块就绪

通电后观察蓝色网络灯：

| 蓝灯状态 | 说明 |
|-----------|------|
| 慢闪 | 正在搜索网络，请等待 |
| **快闪** | ✅ **网络已就绪，可以控制** |

⏱ 从通电到快闪约 **20~30 秒**。

---

## 3. 手机远程控制

打开手机浏览器访问：

**https://xiaoyezi-ysu.github.io/led-controller/led_app.html**

操作步骤：

1. 点击 **连接** 按钮
2. 在设备列表中点击 **车牌 89860812192380777521**
3. 点击 **红灯 / 黄灯 / 绿灯 / 关闭** 控制灯光
4. 拖动 **亮度滑块** 调节亮度

---

> 📌 设备号已固定为 `89860812192380777521`，无需修改。如无响应，请检查蓝灯是否为 **快闪** 状态。
